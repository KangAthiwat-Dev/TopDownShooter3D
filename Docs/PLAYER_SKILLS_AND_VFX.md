# ระบบพัฒนาสกิลและเอฟเฟกต์ต่อสู้

ติดตั้งใน `Assets/_Project/Scenes/WorldPrototype.unity` วันที่ 28 ตุลาคม 2026 ตามรายการความสามารถใน UpSkills.pdf และคำยืนยันว่า “กระสุนวงกว้าง” หมายถึง Explosive Shot

## วิธีเล่น

- กด **C** หรือปุ่ม **พัฒนาสกิล** บน HUD แล้วใช้เมาส์เลือกแท็บ/ปุ่ม **+1**
- เลเวลเพิ่มได้ 1 แต้ม ใช้แต้มร่วมกับระบบพัฒนาผู้เล่นเดิม อัปครั้งละ 1 แต้ม และเริ่มต้นไม่มีแต้มฟรีที่เลเวล 1
- หน้าสกิลและคำอธิบายเป็นภาษาไทย แยก **สกิลต่อสู้ 8 รายการ** กับ **พลังพื้นฐาน 3 รายการ**
- กด C หรือ Esc ปิดเมนู เกมหยุดระหว่างเลือก และป้องกันการเปิดซ้อนร้านค้า กระเป๋า บันทึกเควส หรือเกมโอเวอร์
- สกิลเป็นความสามารถติดตัวตามขั้นที่อัป ใช้ปุ่มยิง/โจมตี **J**, พุ่งสั้น **Space** และแปลงร่าง **M** เดิม ไม่เพิ่มปุ่มกดสกิลอีกชุด
- เลือกอัปหลายสายผสมกันได้ ไม่ต้องเลือกกระสุนด้วยมือ และยังบันทึกแต้ม/ขั้นสกิลอัตโนมัติ

| --- | --- | --- |
| Arcane Barrage | กระสุนกระจาย | 3 ขั้น; ยิง 1 → 3 → 5 → 7 นัดต่อจังหวะ แผ่ออกด้านหน้าทีละ 6 องศา นัดข้างดาเมจ 50% ของนัดหลัก |

พลังพื้นฐานเดิมยังมี **พลังงาน**, **ระยะเวลาแปลงร่าง** และ **พลังยิง** สูตรเดิมยังอยู่ สกิลใหม่เริ่มที่ขั้น 0 ส่วนที่เคยอัปยังคงเดิม

ตัวเลขเหล่านี้เป็นค่าตั้งต้นสำหรับปรับสมดุลต่อ ไม่จำเป็นต้องอัปครบทุกสาย เลเวลสูงสุดยังเป็น 100 และมีแต้มที่หาได้รวม 99 แต้ม

## การทำงานของกระสุนผสม

ยิงกระจายยังใช้จังหวะ **ชุดละ 3 จังหวะ** ของปืนเดิม แต่ละจังหวะจึงเป็นหนึ่ง volley ที่มีหลายกระสุน ใช้เสียงยิง แสงปากกระบอก และคูลดาวน์ครั้งเดียวต่อ volley

กระสุนทุกลูกเริ่มจากปลายปืนจริง นัดหลักเดินทางตามแนวปลายกระบอก นัดข้างหมุนออกตามมุมกระจาย ไม่มีการหักกระสุนตามศัตรูระหว่างบิน

ถ้าอัปทั้งทะลุและระเบิด กระสุนจะทำดาเมจตรงขณะทะลุ แล้วระเบิดเมื่อถึงเป้าสุดท้าย ชนฉาก หรือหมดอายุ เป้าที่โดนตรงไปแล้วจะไม่โดนดาเมจระเบิดซ้ำจากกระสุนลูกเดียวกัน ส่วนมอนสเตอร์ข้างเคียงที่อยู่ในระยะและไม่มีสิ่งกีดขวางรับดาเมจวงกว้างได้

มีการกวาดเส้นทางกระสุนระหว่าง physics step เพื่อช่วยตรวจผนังบาง/เป้าใกล้ และแยกมอนสเตอร์ตาม `EnemyHealth` จึงไม่คิดดาเมจซ้ำจากหลาย collider ของตัวเดียวกัน รวมถึงกรณีถูกยิงตายระหว่างทะลุ

ใช้สำเนาเอฟเฟกต์ใน `Assets/_Project/CombatSkills` เก็บแพ็กต้นฉบับไว้ ถอดเสียง collider rigidbody แสง และ demo MonoBehaviour ที่ไม่จำเป็นออก ทุก burst มีอายุจำกัด ไม่เกิด loop ค้างบนฉาก ตอนติดตั้งสกิลเดิมยังไม่เพิ่มเสียง ส่วนเสียงดาบเพิ่มภายหลังตามหัวข้อด้านล่าง เสียงปืนเดิมยังใช้ตามปกติ

Thunder Dash ยกเว้น collision เฉพาะตัวมอนสเตอร์ชั่วคราว ไม่ยกเว้นกำแพง/พื้น และคืน collision หลังพ้นตัวมอนสเตอร์ หากพุ่งจบอยู่ในตัวมอนสเตอร์ใหญ่จะรอให้แยกออกก่อน เพื่อไม่ให้ physics ผลักผู้เล่นกระเด้ง

## เซฟและโค้ดสำหรับพัฒนาต่อ

- key เซฟเลเวลเดิม `TopDownShooter3D.Progression.v1` ใช้ข้อมูล **version 3** และ 11 upgrade IDs
- อ่าน version 1 และ version 2 ได้ ID 0–4 ของ Vitality/Endurance/Transformation/Firepower/FireRate คงเดิม ไม่มีการรีเซ็ตเลเวล EXP แต้ม หรือ Gold
- `PlayerProgressionState.MaximumRank` กำหนดเพดานสกิล, `TryUpgrade` ตรวจแต้มและสถานะผู้เล่นก่อนจ่ายแต้ม
- `PlayerCombatSkills` กำหนดค่ากระจาย ดาเมจข้าง อัตราดาเมจระเบิด คริติคอล ฟื้นเลือด และพุ่งสายฟ้า ค่าที่มี SerializeField ปรับจาก Inspector ได้
- `PlayerUpgradeStats` ยังดูแลเลือด พลังงาน เวลาแปลงร่าง พลังยิง และความถี่เดิม
- `PlayerRangedWeapon` สร้าง volley จากปลายปืน แล้วถ่ายค่าความสามารถลงกระสุน ณ เวลายิง
- `Projectile` ตรวจชน ทะลุ ระเบิด การบังด้วยฉาก และรายชื่อเป้าที่โดนไปแล้ว
- `PlayerMeleeAttack.SwingCommitted` เป็นจุดเล่น VFX ตามจังหวะฟัน; การยืนยัน hit เดิมยังอยู่
- `PlayerSkillFeedback` ดูแลภาพของดาบ พุ่ง คริติคอล และฟื้นเลือด ไม่เป็นผู้คำนวณดาเมจ
- `PlayerUpgradePanelUI` ดูแลแท็บภาษาไทยและแต้มร่วมกับ pause/input gate เดิม
- `PlayerSkillsSetup` ติดตั้งและปรับสำเนา VFX พร้อม backup ฉากก่อนเปลี่ยน ไม่ติดตั้งซ้ำทับค่าที่ปรับเอง

Material `ArcaneExplosionFire`, `ArcaneOrbFire`, `SwordSlashBlue` และ prefab ของสกิลอยู่ใน `CombatSkills` จึงปรับรูปลักษณ์ภายหลังได้โดยไม่เปลี่ยน asset ต้นทาง

## การตรวจสอบ

เมนู **Tools → Player Skills → Run Skills Combat Save and VFX Test** ทดสอบการย้ายเซฟเก่า แต้ม/เพดานทุกสกิล ปุ่ม C และปุ่มอัปเกรด ดาเมจจริง หลาย collider ผนัง กระสุนผสม จังหวะยิงจริง จังหวะฟัน และพุ่งผ่านมอนสเตอร์ ผลอยู่ใน `Logs/PlayerSkillsPlaytest.txt` ภาพอยู่ใน `Logs/SkillTests/`

เมนู **Run Baseline Movement and Burst Compatibility** ใช้ regression เดิมตรวจอัปเกรด 5 ค่า การเดิน/วิ่ง การหันตัว การติดพื้น และการยิงชุดละ 3 นัด ผลอยู่ใน `Logs/PlayerDevelopmentPlaytest.txt`

ชุดทดสอบสำรอง progression, Gold/loadout และ Story ไว้ก่อนเล่น แล้วคืนโปรไฟล์เดิมหลังออก Play Mode ไฟล์สำรองอยู่ใน `Logs/SkillTests/ProfileBackup_*.json` ไม่ใช้ค่าที่อัปเพื่อทดสอบเป็นเซฟของผู้เล่นจริง

ผลล่าสุดหลังติดตั้ง: สกิล/ต่อสู้/เซฟ/VFX ผ่าน 71 รายการ (รวมคืนโปรไฟล์), ระบบพัฒนาผู้เล่น/เดินวิ่ง/ติดพื้น/ยิงเดิมผ่าน 53 รายการ และลำดับ Tutorial/หมู่บ้าน/Alpha Wolf ผ่าน 51 รายการ ไม่มี runtime error ในการทดสอบทั้งสามชุด ตรวจภาพหน้าสกิลและ VFX ที่ Full HD แล้ว
