# แจ้งเตือน เมนูหลัก และแต่งตัวละคร

## ภาพจาก UI/alerts

ใช้ภาพครบ 10 ภาพจากแพ็กเดิม ไม่แก้ไฟล์ PNG ต้นฉบับ ข้อความประกอบและปุ่มเป็นภาษาไทย

| ภาพ | เหตุการณ์ที่ใช้ |
|---|---|
| Defeat | ผู้เล่นตาย แสดงหลังเล่นท่าตายครบ พร้อมกลับจุดอัญเชิญหรือกลับเมนูหลัก |
| Quest Failed | ตายระหว่างภารกิจที่ยัง Active หมายถึงการลองครั้งนี้ไม่สำเร็จ ความคืบหน้าภารกิจเดิมยังคงอยู่ |
| Level Up | ได้ EXP จนเลื่อนเลเวล แสดงเลเวลก่อน/หลังและแต้มพัฒนาที่มี |
| Quest Completed | รับรางวัลเควสสำเร็จ ไม่แสดงซ้ำจากการกดรับรางวัลซ้ำ |
| Game Saved | กด **บันทึกเกม** ในเมนูพักเกม บันทึกจริงผ่านระบบเลเวล กระเป๋า/Gold และเควสเดิม |
| Victory | เคลียร์ลาน Demon Lord หรือ King of Demon |
| ชื่อเมือง/หมู่บ้าน/ป่า/ปราสาท | ชื่อพื้นที่จาก AdventureHudUI เปลี่ยนและคงอยู่เกิน 0.8 วินาที |

แบนเนอร์ทั่วไปเฟดเข้า/ออกโดยไม่หยุดเกมและไม่บังการคลิก คิวที่รออยู่หยุดแสดงระหว่างเปิดหน้าต่างอื่น ยกเว้น Game Saved ที่แสดงเหนือเมนูพักเกมได้ เมื่อตายจะเคลียร์แบนเนอร์ทั่วไปเพื่อให้หน้าตายแสดงชัดเจน

ยังไม่ได้เพิ่มระบบเซฟหรือบทสนทนาให้ NPC Hotel ในงานนี้ ปุ่มบันทึกเกมใช้ข้อมูลที่ระบบเดิมรองรับ ไม่ได้เซฟตำแหน่งยืนหรือสถานะรอบต่อสู้ของบอส

## เมนูหลัก

ฉาก `Assets/_Project/Scenes/MainMenu.unity` ใช้ `UI/Screen/MenuGame.png` เต็มจอ รักษาสัดส่วนภาพ และย้ายปุ่มไปฝั่งซ้าย:

- เข้าสู่การผจญภัย
- ปรับแต่งตัวละคร
- ตัวเลือก
- วิธีเล่น
- ออกจากเกม

หน้า Options ปรับระดับเสียงได้แล้วทั้งเมนูหลักและพักเกม มีเสียงหลัก เพลง เสียงบรรยากาศ เอฟเฟกต์ และเสียง UI ตัวเลือกกล้อง/กราฟิกยังเว้นไว้ทำภายหลัง ระบบ `CameraViewSettings` เดิมยังอยู่ครบ

เมนูพักเกมมีเล่นต่อ ตัวเลือก วิธีเล่น บันทึกเกม กลับเมนูหลัก และออกจากเกม `Esc` ปิดหน้าย่อยก่อนกลับไปยังเมนูเดิม

## เพลงเมนูและระดับเสียง

- หน้า MainMenu เล่น `PeriTune_Emerald_Hill_loop.wav` แบบ streaming และวนซ้ำ เฟดเข้า 1.4 วินาที และเฟดออก 0.3 วินาทีก่อนเข้าเกม เล่นต่อได้ขณะเปิด Options หรือแต่งตัวละคร และถูกทำลายเมื่อออกจากฉากเมนู
- Options มีแถบ 0–100% พร้อมตัวเลข ปรับแล้วมีผลทันที ใช้เมาส์หรือปุ่มลูกศรเมื่อเลือกแถบได้ มีปุ่มคืนค่าเริ่มต้น
- ค่าตั้งต้นคือเสียงหลัก 100%, เพลง 80%, บรรยากาศ 80%, เอฟเฟกต์ 100%, UI 80% เป็นตัวคูณต่อจากระดับเสียงเดิมของแต่ละแหล่ง ไม่ลบจังหวะเฟดเพลงเมืองหรือป่า
- ใช้ `GameAudio.mixer` ใต้ `Assets/_Project/Resources/Audio` โดยเสียงหลักเป็น parent ของอีก 4 กลุ่ม การตั้ง 0% ลดเสียงกลุ่มนั้นถึง -80 dB
- เพลงเมือง เพลงสำรวจ และเพลงเมนูอยู่ใน Music; ป่า หมู่บ้าน และกองไฟอยู่ใน Ambience; ปืน ฝีเท้า เก็บของ ศัตรู และเสียง VFX อยู่ใน Effects; เปิด/ปิด/hover เมนูอยู่ใน UI
- บันทึกแยกใน PlayerPrefs ชื่อ `TopDownShooter3D.Audio.v1` อัตโนมัติหลังปรับเสร็จ 0.3 วินาทีหรือปิด Options ทำงานได้แม้พักเกม และใช้ค่าเดียวกันทุกฉาก ไม่มีการแก้เลเวล ไอเทม เควส หรือรูปลักษณ์
- หากเพิ่ม AudioSource ใหม่ ให้เลือก Output Audio Mixer Group ให้ตรงหมวด หรือเรียก `GameAudioSettings.Route(source, GameAudioBus.Effects)` เป็นต้น prefab ศัตรูและ VFX ในโปรเจกต์ที่ใช้งานปัจจุบันผูกกลุ่มเสียงไว้แล้ว

`Main Menu Emerald Hill Music` ในฉาก MainMenu ปรับ clip, ระดับพื้นฐาน และเวลาเฟดได้จาก Inspector ส่วนค่าบันทึกและ AudioMixer ควบคุมด้วย `GameAudioSettings` ที่มีเพียงตัวเดียวตลอดการเล่น

## เลือกตัวละครก่อนเล่น

ระบบ `PlayerAppearance` เดิมยังอยู่ ใช้ renderer/material slots เดิมด้วย MaterialPropertyBlock จึงไม่ย้อมสีอาวุธ เกราะ หรือตัวละครอื่น

- เลือกสีผิว 6 สี และสีผม 8 สี
- ทรงผม 3 แบบที่โมเดลมี: โกนศีรษะ ผมสั้น และมัดจุก
- พรีวิวโมเดล 3D จริง หมุนซ้าย/ขวาได้
- เข้าเกมครั้งแรกที่ยังไม่เคยบันทึกรูปลักษณ์ จะเปิดหน้านี้ก่อนเริ่มเล่น
- เมื่อมีรูปลักษณ์ที่บันทึกแล้ว กดเข้าเกมได้ทันที หรือแก้จากปุ่มปรับแต่งตัวละคร
- กดยกเลิกหรือ Esc จะทิ้งเฉพาะการแก้ครั้งนั้น ไม่มีการเขียนทับรูปลักษณ์เดิม

บันทึกแยกใน PlayerPrefs ชื่อ `TopDownShooter3D.Appearance.v1` ผ่าน `PlayerAppearanceProfile` ไม่ล้างเลเวล Gold ไอเทม เควส หรืออาวุธ `PlayerAppearanceProfile` บน Player จะนำค่าไปใช้กับโมเดลเมื่อโหลด WorldPrototype

พรีวิวใช้ prefab `Assets/_Project/Prefabs/UI/CharacterMenuPreview.prefab` ที่แยกจากตัวเล่นจริง มีเฉพาะโมเดล Animator และระบบรูปลักษณ์ ไม่มีอาวุธหรือโค้ดการเล่น ใช้กล้อง RenderTexture ที่เปิดเฉพาะตอนเปิดหน้าแต่งตัว

## จุดปรับแต่ง

- ใน World: `Game Alert Canvas > Animated Alert` และรายการ Art บน GameAlertsUI
- หน้าตาย: `HUDCanvas > GameOverPanel` และ GameOverUI
- ใน MainMenu: `Title Menu > Menu Window > Left Main Menu`
- หน้าแต่งตัว: `Title Menu > Character Creator` แก้ palette, ปุ่ม และ prefab พรีวิวใน Inspector

## ตรวจการทำงาน

`Tools > Game Presentation > Test Alerts Menus and Saved Appearance` สำรองและคืนเซฟทั้งเลเวล Gold/loadout เควส และรูปลักษณ์ ผลอยู่ `Logs/PresentationPlaytest.txt` ภาพอยู่ `Logs/PresentationTests` ทดสอบ EXP จริง การรับรางวัลจริง การเซฟจริง หน้าตาย การเปลี่ยนฉาก เมนู Options และการนำรูปลักษณ์ที่เลือกไปใช้กับ Player

`Tools > Audio Options > Test Menu Music Sliders and Saved Mix` ทดสอบผ่าน 40 จุด รวมเสียงที่วัดจาก AudioListener ก่อน/หลังปิดเสียงแต่ละหมวด การปรับขณะพักเกม การคืนค่าเริ่มต้น การเฟดและวนเพลง และการเปลี่ยนฉาก ผลอยู่ `Logs/AudioOptionsPlaytest.txt` ภาพอยู่ `Logs/AudioOptionsTests` สำรอง/คืนเซฟผู้เล่น ค่าระดับเสียง และการ mute เสียงของ Unity Editor เดิมหลังทดสอบ
