# ร้านดาบและการสุ่มสินค้า

ติดตั้งใน `WorldPrototype` บน **NPC_WeaponMerchant** ตัวเดิม (`armory_merchant_01`) ที่หน้าร้านอาวุธ โดยคงตำแหน่ง รูปลักษณ์ และพฤติกรรมมองผู้เล่นที่ผู้ใช้จัดไว้.

## วิธีเล่น

1. เก็บของจากมอนสเตอร์แล้วขายกับ NPC หน้า **Gild** เพื่อรับ Gold.
2. เดินเข้าหาพ่อค้าอาวุธและกด **E**.
3. ใช้เมาส์เลือกดาบ ดูราคาและรายละเอียด แล้วเลือกช่องอาวุธประชิด 1 หรือ 2.
4. กด **ซื้อดาบ**. หากช่องนั้นมีอาวุธอยู่ จะระบุชื่ออาวุธเดิม พร้อมข้อความว่าจะหายไปโดยไม่ได้ Gold คืน และปุ่มจะเป็น **ซื้อและแทนที่อาวุธ**.
5. กด **Esc** หรือ X เพื่อออกจากร้าน.

ซื้อแล้วใช้ Gold ตามราคาที่แสดงเพียงครั้งเดียว ดาบเข้าช่องอาวุธประชิดโดยตรง ไม่กินช่องวัตถุดิบ 8 ช่อง.
ดาบเก็บเฉียงไว้ด้านหลังและชักใช้อัตโนมัติเมื่อศัตรูประชิด ตามระบบอาวุธเดิม.
เมื่อทั้งสองช่องเต็ม จะไม่เลือกช่องแทนที่ให้เอง ผู้เล่นต้องเลือกก่อนซื้อ.
เมื่อซื้อจนของหมด ต้องรอสินค้ารอบถัดไป.

## สินค้าและราคา

แต่ละรอบสุ่มดาบ **3 แบบที่ไม่ซ้ำกัน** จากทั้งหมด 5 แบบ มีแบบละ **1 เล่ม**.
เปลี่ยนสินค้าทุก **300 วินาทีจริง (5 นาที)** รวมช่วงที่เปิดร้าน/หยุดเกมหรือปิดเกมไว้.
หากพ้นเวลาไปหลายรอบระหว่างปิดเกม จะสร้างรอบใหม่หนึ่งรอบเมื่อโหลดกลับมา.
เปิดปิดร้านหรือโหลดฉากใหม่ก่อนครบเวลา จะได้สินค้า ราคา และสถานะขายแล้วชุดเดิม.

| ดาบ | ราคาฐาน | ช่วงราคาสุ่ม | Damage ต่อบอส |
|---|---:|---:|---:|
| ดาบเหล็ก | 90 | 72–108 Gold | 30 |
| ดาบเหมันต์ | 140 | 112–168 Gold | 38 |
| ดาบสุริยะ | 210 | 168–252 Gold | 46 |
| ดาบโบราณ | 300 | 240–360 Gold | 60 |
| ดาบหนามรัตติกาล | 420 | 336–504 Gold | 75 |

ราคาสุ่มในช่วง ±20% ของราคาฐาน ดาบแต่ละรอบมีอย่างน้อยหนึ่งแบบต่างจากรอบก่อน หาก Catalog มีให้เลือกมากกว่าจำนวนสินค้าต่อรอบ.
ดาบที่อยู่ต่อในรอบใหม่จะเปลี่ยนราคาเมื่อช่วงราคามีให้เลือกมากกว่าหนึ่งค่า.
UI แสดงเวลานับถอยหลัง หากเปลี่ยนรอบขณะกำลังเลือกซื้อ จะล้างการเลือกและให้เลือกดาบใหม่ จึงไม่ตัดเงินด้วยราคาใหม่โดยไม่ทราบ.

คงกติกาประชิดเดิม: มอนสเตอร์ที่อนุญาต Instant Kill จะถูกกำจัดในครั้งเดียว ส่วนบอสรับ Damage ตามตาราง ระยะโจมตี 2.5 เมตร.
ใช้ Animation และระบบวาด/เก็บอาวุธเดิม ยังไม่มีเอฟเฟกต์ธาตุจากชื่อดาบ.

## การบันทึก

- `TopDownShooter3D.Gold.v1`: Gold, ID ดาบทั้ง 2 ช่อง และช่องที่เลือก บันทึกใน JSON เดียวกันตอนซื้อ.
- `TopDownShooter3D.WeaponMerchant.armory_01.v1`: สินค้า ราคา ขายแล้ว และเวลาสุ่มรอบถัดไป.
- ใช้ Weapon ID คงที่ เช่น `fantasy_sword_01` และ `training_club`; ไม่พึ่งชื่อที่แสดงหรือรูปไอคอน.
- รองรับเซฟ Gold รุ่นเดิมที่ยังไม่มีข้อมูลอาวุธ.
- การเก็บอาวุธจากพื้นและการเลือกช่องอาวุธจะบันทึกด้วย เพื่อไม่ให้ข้อมูลที่ซื้อไว้ถูกเขียนทับด้วยสถานะเก่า.
- ข้อมูลเสียหรือเวอร์ชันที่ไม่รองรับจะไม่ถูกนำมาทับสถานะที่ใช้ได้.

## จุดปรับแต่ง

เลือก NPC ในฉาก ดู Component `WeaponMerchant`:

- `Catalog`: Weapon Definition และราคาฐานแต่ละแบบ
- `Offer Count`: จำนวนสินค้าต่อรอบ สูงสุด 3 ตามหน้าร้านปัจจุบัน
- `Refresh Seconds`: ช่วงเวลาเปลี่ยนสินค้า ค่าเริ่มต้น 300
- `Price Variation`: สัดส่วนสุ่มราคา ค่าเริ่มต้น 0.2
- `Interaction Range`: ระยะคุยกับพ่อค้า

ข้อมูลดาบอยู่ใน `Assets/_Project/Prefabs/Weapons/FantasySwords/Definitions/`.
ไอคอนมาจากการ Render โมเดลจริง อยู่ใน `.../FantasySwords/Icons/`.
หากเพิ่มดาบชนิดใหม่ ต้องเพิ่ม Definition ใน Catalog ของร้านและ `Weapon Catalog` ของ `PlayerGoldWallet` เพื่อให้โหลดอาวุธจากเซฟกลับได้.

โค้ดหลัก:

- `WeaponMerchant.cs`: สต็อก สุ่มราคา เวลา Interaction และตรวจรายการก่อนซื้อ
- `WeaponShopUI.cs`: หน้าร้าน การเลือกช่อง การแสดงราคาและปิดหน้าต่าง
- `PlayerMeleeEquipment.cs`: เพิ่ม/เปลี่ยนอาวุธพร้อมหักเงิน ก่อนแจ้ง Event
- `PlayerGoldWallet.cs`: บันทึก Gold และอาวุธร่วมกัน
- `WeaponShopSetup.cs`: ติดตั้งข้อมูลดาบ ไอคอน และหน้าร้าน โดยไม่วาง NPC เพิ่ม

## ตรวจสอบใน Unity

เมนู `Tools > NPC > Weapon Merchant > Run Shop Purchase Rotation and Save Test`
ทดสอบกด E และคลิกเมาส์ผ่าน Input System จริง รวมเงินไม่พอ ซื้อซ้ำ ช่องเต็ม เปลี่ยนอาวุธ สุ่มสินค้า ราคาเก่า การนับเวลาขณะ Pause และโหลด Save กลับด้วย instance ใหม่.
ใช้โปรไฟล์ชั่วคราวและคืน Gold/อาวุธ/สต็อกเดิมของผู้ใช้หลังจบ.

รายงาน `Logs/WeaponShopPlaytest.txt` และภาพ `Logs/WeaponShop_Purchase.png`, `Logs/WeaponShop_Restock.png`.

ตรวจผ่าน 59 รายการสำหรับร้านดาบ และตรวจระบบขายกิลด์เดิมผ่านอีก 40 รายการหลังเชื่อมกระเป๋าเงินกับอาวุธ.
ตรวจภาพหน้าร้าน/กระเป๋า ไอคอนพื้นโปร่งใส ชื่อดาบภาษาไทยบน HUD และไม่พบ Runtime Error หรือคำเตือน Glyph หายในรอบสุดท้าย.
