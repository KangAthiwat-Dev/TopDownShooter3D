# พัฒนาผู้เล่น ปืน Burst และการเคลื่อนที่เกาะพื้น

ฉาก: `Assets/_Project/Scenes/WorldPrototype.unity`

## ปืนเริ่มต้น

- ดาเมจเริ่มต้น 8 ต่อกระสุนหนึ่งนัด
- กด J ค้างเพื่อยิงเป็นชุดละ 3 นัด ห่างกันนัดละ 0.2 วินาที
- หลังนัดที่สามพัก 0.8 วินาที จึงเริ่มชุดใหม่
- ปล่อยปุ่มแล้วหยุดทันที ถ้ายังยิงไม่ครบชุดจะมีเวลาพักก่อนเริ่มใหม่ ป้องกันการกดรัวข้ามช่วงพัก
- นับเฉพาะกระสุนที่ยิงออกจริง รอท่าเล็งและปลายกระบอกตรงเป้าก่อนเหมือนระบบเดิม
- กระสุนยังออกตามทิศปลายปืนโดยตรง ไม่เปลี่ยนทิศกลางทาง
- ยิงได้ขณะเคลื่อนที่ อาวุธประชิดและท่าเดิมยังใช้ระบบเดิม

ค่าตั้งต้นแก้ที่ `PlayerAttackController` และ `PlayerRangedWeapon` บน Player

## เลเวลและการเลือกอัปเกรด

กด **C** หรือ **Start บน gamepad** เปิดหน้า Character Development มีปุ่มเปิดอยู่ใต้แถบพลังงานด้วย
ได้ 1 แต้มต่อเลเวล เก็บแต้มไว้เลือกภายหลังได้ ไม่เปิดเมนูอัตโนมัติขณะต่อสู้
แต่ละสายใช้ครั้งละ 1 แต้ม สูงสุด 20 ขั้นต่อสาย โดยเลเวล 100 มีแต้มรวม 99 แต้ม

| สาย | ผลต่อหนึ่งขั้น |
|---|---|
| Vitality | เลือดสูงสุด +15 และลดความเสียหายที่ได้รับเพิ่ม 1% |
| Endurance | พลังงานสูงสุด +10 ใช้ทั้ง Sprint และแปลงร่าง |
| Transformation | เพิ่มตัวคูณระยะเวลาแปลงร่าง +8% ของเวลาพื้นฐาน โดยลดอัตรากินพลังงาน |
| Firepower | ดาเมจกระสุนเพิ่ม 12% ของค่าปืนพื้นฐาน |
| Fire Rate | เพิ่มความถี่ 6% ลดทั้งระยะห่างระหว่างนัดและเวลาพักระหว่างชุด |

ตัวเลขเป็นค่าเบื้องต้น แก้ได้ที่ `PlayerUpgradeStats` บน Player
เลือด/พลังงานที่เพิ่มจะเพิ่มความจุปัจจุบันตามส่วนต่าง แต่การเพิ่มเลือดไม่ชุบชีวิตผู้เล่นที่ตายแล้ว

หน้าพัฒนาผู้เล่นหยุดเกม ใช้เจ้าของ pause เดียวกับกระเป๋า และเปิดซ้อนกับกระเป๋าไม่ได้
หลอดเลือดและพลังงานใน HUD ยังแสดงโดยไม่มีตัวเลขตามการออกแบบเดิม

## การวิ่งและพลังงาน

- เดินเคลื่อนที่ปกติยังเป็น Run ที่ 5 เมตร/วินาที ไม่กินพลังงาน
- Shift เป็น Sprint ใช้ความเร็วที่ตั้งไว้เดิมในฉาก 10 เมตร/วินาที
- Sprint กินพลังงาน 18 หน่วย/วินาที จากหลอดสีน้ำเงินร่วมกับการแปลงร่าง
- เริ่มต้นพลังงาน 100 จึง Sprint ต่อเนื่องได้ประมาณ 5.5 วินาที และแปลงร่างประมาณ 3.3 วินาที
- ถ้าพลังงานหมด Sprint จะกลับมา Run และต้องปล่อย Shift ก่อนเริ่ม Sprint ใหม่ ไม่กระตุกสลับวิ่งเร็วกับช้าเมื่อพลังงานเริ่มฟื้น
- ฟื้นพลังงานตามระบบเดิมหลังหยุดใช้ 0.75 วินาที อัตรา 20 หน่วย/วินาที

## การเคลื่อนที่และแอนิเมชัน

- แยกการเร่งความเร็วออกจากการเปลี่ยนทิศ เลือกทิศใหม่ได้ทันที โดยยังผสมท่าหมุนตัว
- ปรับ acceleration 48, deceleration 60 และ turn speed 24 เริ่ม/หยุดไวขึ้น
- ใช้ CharacterController.Move ครั้งเดียวต่อเฟรม พร้อมตรวจพื้นตำแหน่งถัดไป
- เกาะทางลาดและขั้นลงใกล้ตัวได้ถึง 0.6 เมตร ใช้ gravity 30 กับการตกจากพื้นที่สูงกว่านั้น
- ตรวจพื้นเฉพาะ layer Environment ไม่ดึงตัวไปยืนบนมอนสเตอร์หรือไอเทม
- ปรับ skin width เป็น 0.03 และ step offset เป็น 0.35
- พารามิเตอร์ทิศทางแอนิเมชันผสมตามมุมบนวงกลม ไม่ไล่ผ่านจุดกลางซึ่งเคยผสมท่ายืนนิ่งตอนกลับทิศ
- นำ Idle ที่จุดกลางออกจากต้นไม้ทิศทาง โดยต้นไม้ระดับ gait ยังคุม Idle/Walk/Run/Sprint
- เพิ่ม `LocomotionRate` ให้ความถี่ก้าวสัมพันธ์กับความเร็วจริง ใช้เฉพาะสถานะ Locomotion จึงไม่เร่งท่าต่อย เก็บของ Dash หรือท่าเข้า/ออกแปลงร่าง
- แอนิเมชันยังเป็น in-place และปิด root motion ใช้ CharacterController เป็นเจ้าของตำแหน่ง

ปรับความรู้สึกได้ที่ PlayerMovement และค่าความเร็วแอนิเมชันใน PlayerAnimationController

## เซฟและโครงสร้างโค้ด

- `PlayerProgressionState` เก็บเลเวล EXP และอันดับทั้ง 5 สาย แต้มที่เหลือคำนวณจาก level - 1 - แต้มที่ใช้
- บันทึกข้อมูล version 2 ใน key เดิม `TopDownShooter3D.Progression.v1` เพื่ออ่านเซฟก่อนหน้าได้
- เซฟ version 1 ยังโหลดได้และให้แต้มตามเลเวลเดิม โดยยังไม่เลือกสายให้เอง
- ตรวจขนาด array อันดับสูงสุดและจำนวนแต้มก่อนรับเซฟ ปฏิเสธข้อมูลเสียโดยไม่เขียนทับสถานะปัจจุบัน
- `PlayerUpgradeStats` แปลงอันดับเป็นค่าที่ใช้จริง
- `PlayerUpgradePanelUI` แสดงค่าและส่งคำขอใช้แต้มผ่าน TryUpgrade
- UI เพิ่ม action `Menus/Upgrades` ใน `Assets/_Project/Input/PlayerControls.inputactions`
- ค่า EXP และ rank เดิม รวมถึงเพดานเลเวล 100 ยังใช้เส้นโค้งเดิม
- ระบบนี้บันทึกเลเวลกับอัปเกรด ส่วนเซฟกระเป๋า/Hotel ยังเป็นระบบแยกที่ยังไม่ได้ทำในงานนี้
