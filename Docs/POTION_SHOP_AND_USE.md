# ร้าน Potion และการใช้งาน

เชื่อมร้านเข้ากับ `NPC_PotionStore_Female` ตัวเดิมหน้า Potion Store โดยไม่ย้ายตำแหน่งที่ผู้ใช้จัดไว้.
เดินเข้าหา NPC แล้วกด **E** ใช้เมาส์เลือกขวด จำนวน และกดซื้อ กด **Esc** หรือ X เพื่อปิดร้าน.
ใช้ Gold กระเป๋าเดียวกับร้านดาบและกิลด์ สินค้า Potion ทั้ง 3 แบบมีขายตลอด ราคาคงที่.

| ขวด | ผล | ราคา |
|---|---|---:|
| แดง — โพชั่นฟื้นเลือด | ฟื้น 50% ของเลือดสูงสุด ไม่เกินหลอดเต็ม | 25 Gold |
| ฟ้า — โพชั่นฟื้นพลัง | ฟื้น 60% ของพลังสูงสุด สำหรับวิ่งและแปลงร่าง | 20 Gold |
| เขียว — โพชั่นเกราะเวท | ลดความเสียหายที่ยังเหลืออีก 20% นาน 30 วินาทีขณะเล่น | 40 Gold |

ตัวอย่าง: ถ้าอัปเกรดลดดาเมจถาวร 10% และใช้ขวดเขียว จะได้รับดาเมจ `0.9 × 0.8 = 72%` ของเดิม ไม่เขียนทับค่าที่อัปเกรดไว้.

## กระเป๋าและการใช้

- ซื้อครั้งละ 1–10 ขวด; เก็บซ้อนสูงสุด 10 ขวดต่อกองในช่องวัตถุดิบ 8 ช่อง อาวุธประชิด 2 ช่องแยกเหมือนเดิม.
- ถ้าช่องเต็มแต่กอง Potion เดิมยังมีที่ จะซื้อเติมกองได้ ถ้าที่ไม่พอจะไม่ตัด Gold และไม่ซื้อให้บางส่วน.
- เปิดกระเป๋า เลือก Potion แล้วกดปุ่ม **ใช้ Potion** ในรายละเอียด.
- เลือดหรือพลังเต็มจะไม่กินขวด และปิดปุ่มใช้พร้อมบอกเหตุผล.
- เกราะเวทไม่ซ้อนทับและไม่ต่อเวลาด้วยการกดขวดซ้ำขณะที่ยังมีผล.
- เกราะเวทหยุดนับระหว่าง Pause/เปิดกระเป๋า มีข้อความเวลาคงเหลือใต้ Gold บน HUD.
- ไม่ใช้ Potion ระหว่างคุยกับร้าน วิ่ง Dash/แปลงร่าง หรือตายแล้ว; ขวดแดงไม่ชุบชีวิต.
- กิลด์รับซื้อเฉพาะ Resource ตามเดิม จึงไม่รับซื้อ Potion.

## การบันทึก

ขยาย JSON เดิมของ `PlayerGoldWallet` (`TopDownShooter3D.Gold.v1`) ให้มี Item ID และจำนวนทั้ง 8 ช่องร่วมกับ Gold และอาวุธ 2 ช่อง.
การซื้อจึงบันทึกทั้งเงินที่จ่ายและของที่ได้ในข้อมูลชุดเดียวกัน ใช้ขวดแล้วบันทึกจำนวนที่เหลือทันที.
ของดรอปที่เก็บ การขาย และการเปลี่ยนของในช่องวัตถุดิบจะบันทึกด้วย.
รองรับเซฟเก่าที่มีแค่ Gold/อาวุธ ไม่มีการแจก Potion เริ่มต้นหรือแก้จำนวนเงินเดิม.
เลือด พลัง และบัฟชั่วคราวไม่ถูกเก็บในเซฟนี้; เกราะเวทไม่ค้างข้ามการโหลดเกม.

ไอเทมที่ต้องโหลดกลับต้องอยู่ใน `Item Catalog` ของ `PlayerGoldWallet`.
ตัวติดตั้งเพิ่ม Resource เดิมทั้ง 8 ชนิดและ Potion ทั้ง 3 ให้แล้ว ถ้าเพิ่ม Item Definition ใหม่ภายหลัง ให้เพิ่มใน Catalog ด้วย.

## จุดปรับแต่ง

- เลือก NPC ดู `PotionMerchant > Catalog` เพื่อปรับราคาต่อขวด.
- เลือก Item Definition ดู `Potion Effect`, `Potion Strength` และ `Potion Duration` เพื่อปรับผลของขวด.
- `Potion Strength` เป็นสัดส่วน เช่น 0.5 = 50%, 0.2 = 20%.
- `PlayerPotionUse`: ตรวจเงื่อนไขและใช้ขวด.
- `PlayerHealth`/`PlayerEnergy`: ฟื้นฟูและคำนวณเกราะชั่วคราวแยกจากอัปเกรด.
- `PotionShopUI`: หน้าซื้อและจำนวน; `InventoryPanelUI`: ปุ่มใช้จากกระเป๋า.
- เมนูติดตั้ง `Tools > NPC > Potion Shop > Install Three Potions and Shop` จะไม่เขียนทับร้านที่ติดตั้งแล้ว.

## การตรวจสอบ

เมนู `Tools > NPC > Potion Shop > Run Purchase Use and Save Test` ทดสอบ E/เมาส์จริง การซื้อหลายขวด เงินไม่พอ กระเป๋าเต็ม การใช้ทั้งสามแบบ การหมดบัฟ การป้องกันข้อมูลเก่า และโหลดเซฟด้วย Player instance ใหม่.
ทดสอบด้วยโปรไฟล์ชั่วคราวและคืน Gold/อาวุธ/ของในกระเป๋าเดิมเมื่อจบ.
รายงานใน `Logs/PotionShopPlaytest.txt`; ภาพใน `Logs/PotionShop_Store.png`, `Logs/PotionShop_Use.png`, `Logs/PotionShop_FullBag.png`.

ตรวจผ่าน 62 รายการของร้าน Potion พร้อมตรวจร้านดาบเดิมผ่าน 59 รายการและกิลด์ผ่าน 40 รายการหลังขยายการบันทึกกระเป๋า.
ตรวจภาพ UI/ขวด/การใช้ในกระเป๋า และไม่พบ Runtime Error, Missing Script หรือคำเตือน Glyph หายในรอบสุดท้าย.
