# Story — Tutorial, Oakshade Defense และ Alpha Wolf

ติดตั้งใน `Assets/_Project/Scenes/WorldPrototype.unity` วันที่ 28 ตุลาคม 2026 ตาม Story.pdf ฉาก 01–03

## ลำดับที่เล่นได้

1. เกิดที่ Summoning Ruins พร้อมปืนและ mini-map เดิม มีเป้าหมายหลัก **Defeat Malachar** บน HUD และบันทึกภารกิจ
2. Tutorial ตรวจ **เดินจริง 8 เมตรด้วย WASD**, **ยิงจริงด้วย J อย่างน้อยหนึ่งนัด** และ **พุ่งหลบด้วย Space สำเร็จหนึ่งครั้ง** ทำสลับลำดับได้ การวาร์ป เปิดเมนู หรือกดค้างระหว่างปิดเมนูไม่นับเป็นการฝึก
3. มีเป้าฝึกไม้ใกล้จุดเกิดให้ใช้ระบบเล็ง/ยิงเดิม เป้าไม่โจมตี ไม่ให้ EXP หรือ loot และเลิกใช้งานหลังฝึกยิงสำเร็จ
4. เมื่อฝึกครบ เป้าหมายเปลี่ยนเป็น **Explore Everwood → ไปพบทหารยามที่ Oakshade Village**
5. เข้าใกล้ทหารยาม กด **E** แล้วใช้เมาส์เลือกรับ **Defend the Village** หรือออกจากบทสนทนาไว้ก่อน
6. ต่อสู้กับ Goblin/Skeleton เฉพาะเหตุการณ์ **3 ระลอก ระลอกละ 2 ตัว** รวม 6 ตัว มอนสเตอร์ชุดนี้เน้นโจมตีผู้เล่น ใช้ AI/เสียง/ท่าเดิน วิ่ง โจมตี ตาย ของ prefab เดิม และมี HP 24/32, damage 5/6 เพื่อให้ช่วงต้นเกมเล่นผ่านได้
7. กำจัดครบแล้วกลับไปส่งภารกิจที่ทหารยาม รับ **100 Gold + Beast Hide 2 ชิ้น**
8. ทหารยามเสนอ **Hunt the Alpha Wolf** ต่อ รับภารกิจแล้วตาม marker ไปหา Wolf Boss ใน Thornveil Forest
9. ต้องเป็นผู้เล่นที่ลงมือสังหาร Alpha Wolf หลังรับภารกิจ จากนั้นกลับไปส่งเควส รับ **180 Gold + Wolf Fang 1 ชิ้น**
10. บทสนทนาหลังส่งครบเปลี่ยนเป็นขอบคุณ/แนะนำให้เตรียมตัวที่ Silverwell และไม่มีปุ่มรับรางวัลซ้ำ

**E** สนทนา · **Q** เปิด/ปิดบันทึกภารกิจ · **Esc** ปิดหน้าต่าง · ใช้เมาส์เลือกคำตอบ

HUD ด้านซ้ายแสดงภารกิจปัจจุบัน จำนวนศัตรูที่กำจัด และทิศ/ระยะทาง Marker `!` สีทองบน mini-map เปลี่ยนจากทหารยาม → ผู้บุกรุก → Alpha Wolf → กลับไปส่งเควสตามลำดับ หน้าบันทึกแสดงสถานะภารกิจที่ยังล็อก รับได้ กำลังทำ รอรับรางวัล และสำเร็จแล้ว

## เงื่อนไขที่ป้องกันเควสค้างหรือรางวัลซ้ำ

- ศัตรูที่เกิดจากระบบโลกหรือ wave เดิมไม่นับเป็นผู้บุกรุกของเควส มี `VillageDefenseMember` พร้อม slot คงที่แยกต่างหาก
- ใช้ `EnemyHealth.Died` เท่านั้น การ disable/destroy/despawn ไม่ถือว่าฆ่า หากสมาชิกหายไปจะสร้าง slot นั้นกลับมาเมื่อพื้นที่พร้อม
- เมื่อโหลดฉากใหม่ เก็บ kill mask ของผู้บุกรุกไว้ สร้างเฉพาะตัวที่ยังไม่ตายในระลอกปัจจุบัน และค่อยเริ่มระลอกถัดไปหลังจบระลอกนั้น
- การเกิดตรวจ NavMesh, เส้นทางกลับพื้นที่ต่อสู้ และ collider ของสิ่งกีดขวาง หากเกิดไม่ได้จะรอแล้วลองใหม่ ไม่ข้าม objective
- การต่อสู้ดำเนินเมื่อผู้เล่นอยู่ใกล้พื้นที่ทหารยามภายใน 55 เมตร
- ใช้ Alpha Wolf หนึ่งตัวใน `WorldMonsterDirector` ที่มีอยู่ ไม่เพิ่ม Wolf Boss อีกชุด หากมันตายก่อนรับเควสหรือไม่ได้ตายด้วยฝีมือผู้เล่น เควสรอให้ประชากรป่าเกิดใหม่ตามกฎเดิม
- Wolf Fang เป็นรางวัลส่งเควสครั้งเดียว ใช้ icon เขี้ยวเดิม ขายให้กิลด์ได้ **60 Gold** และอยู่ใน `itemCatalog` เพื่อให้โหลดกลับเข้ากระเป๋าได้
- กระเป๋าไม่พอหรือ Gold เต็มจะปฏิเสธ **ทั้งรางวัล** ไม่มีการให้ Gold ไปก่อนหรือทำของหาย กลับมาส่งเควสใหม่ได้
- Gold + ไอเทม + ใบรับรางวัลบันทึกในธุรกรรมเดียวกัน หากเกมหยุดระหว่างบันทึก wallet กับ story ระบบจะตรวจใบรับรางวัลและซ่อมสถานะภารกิจโดยไม่จ่ายซ้ำ
- บทสนทนาและ journal ใช้ `GamePauseController` ร่วมกับกระเป๋า/ร้านค้า/เกมโอเวอร์ ปิดหน้าต่างหนึ่งไม่ปลด pause ของอีกหน้าต่าง และต้องปล่อยปุ่มโจมตี/พุ่งก่อนเริ่มใช้ใหม่

## เซฟและความเข้ากันได้

| ข้อมูล | ตำแหน่ง/รูปแบบ |
| --- | --- |
| Story | PlayerPrefs `TopDownShooter3D.Story.v1` — version 1 |
| สิ่งที่เก็บ | ระยะเดิน, ยิง/พุ่งสำเร็จ, เคยคุยทหารยาม, สถานะสองเควส, kill mask |
| Gold/อาวุธ/กระเป๋า | key เดิม `TopDownShooter3D.Gold.v1` — เพิ่มรูปแบบ version 2 พร้อม `questReceipts` และยังอ่าน version 1 ได้ |
| เลเวล/อัปเกรด | ใช้ระบบและ key เดิม ไม่รีเซ็ตเมื่อเริ่มเนื้อเรื่อง |
| ตำแหน่งหลังโหลด | จุดอัญเชิญเดิม ยังไม่มี checkpoint น้ำพุหรือ Hotel save |

บันทึกเมื่อเป้าหมายเปลี่ยน รับ/ส่งเควส และทุกระยะเดินครบเมตรของ tutorial ส่วนที่สำเร็จอยู่แล้วไม่ต้องทำซ้ำเมื่อเริ่มเกมใหม่

## การตรวจสอบ

เมนู **Tools → Story → Run First Three Steps Play Test** ทดสอบจริงใน Play Mode ทั้ง WASD/J/Space/E, pause, บทสนทนา, ศัตรู 3 ระลอก, kill attribution, ของเต็ม/Gold เต็ม, รางวัลครั้งเดียว และโหลดฉากจริงระหว่างเควสกับหลังรับรางวัล ผลอยู่ใน `Logs/StoryQuestPlaytest.txt` และภาพใน `Logs/StoryTests/`

ชุดทดสอบสำรอง PlayerPrefs เดิมไว้ใน SessionState และ `Logs/StoryTests/ProfileBackup_*.json` แล้วคืนข้อมูลเดิมเมื่อออก Play Mode ไม่ใช้โปรไฟล์ทดสอบเป็นความคืบหน้าของผู้เล่นจริง ส่วนเมนู **Test Existing Guild Compatibility** / **Test Existing Potion Compatibility** ใช้ชุดทดสอบร้านค้าเดิมภายใต้การสำรองโปรไฟล์เดียวกัน

ผลตรวจล่าสุด: Story ผ่าน 50 เงื่อนไขการเล่น + การคืนโปรไฟล์เดิม, กิลด์ผ่าน 40 เงื่อนไข และร้านยาผ่าน 62 เงื่อนไข ไม่มี runtime error ในชุดทดสอบทั้งสาม ตรวจภาพหน้าสนทนา/บันทึกที่ Full HD และลองกด Q กับคลิกเมาส์ปิดหน้าต่างในเกมจริงแล้ว

## ส่วนของ Story ที่ทำภายหลัง

เป้าหมายหลัก Defeat Malachar ถูกประกาศแล้ว รอบนี้ยังไม่ต่อ dialogue gate ของ Malachar, phase 2, main-quest completion/Victory, opening video, Wood Golem/Golem Core, first/repeat story dialogue ของร้านค้า หรือ checkpoint น้ำพุ/Hotel สิ่งเหล่านี้เป็นงานช่วงถัดไป
