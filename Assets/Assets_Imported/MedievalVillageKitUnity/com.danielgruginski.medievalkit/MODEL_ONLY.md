# Medieval Village Kit — Model-only

ชุดนี้เก็บเฉพาะงานภาพสำหรับนำมาจัดฉากในเกม ไม่ใช้ระบบเกมหรือเครื่องมือ C# ของแพ็กต้นฉบับ

- ลากชิ้นส่วนจาก `Generated/Prefabs/` หรืออาคารสำเร็จรูปจาก `Generated/Structures/` ลงซีนได้ตามปกติ
- เก็บโมเดล, texture, material, shader, collider และ GUID เดิมไว้
- ถอด `KitPiece` / `KitStructure` ออกจาก prefab แล้ว ไม่มีตัวละครทดลอง ระบบ auto-snap หรือเครื่องมือสร้างเมืองทำงานแทรก
- เก็บ `Shaders/` ไว้ด้วย วัสดุเดิมยังต้องใช้ shader เหล่านี้เพื่อแสดงผลเหมือนเดิม
- ถ้าวัตถุใดไม่มี collider และต้องการให้ชน ต้องเพิ่ม collider ที่เหมาะสมเอง

แพ็กต้นฉบับและซีนก่อนแก้สำรองไว้นอก `Assets` ที่:

`Backups/MedievalVillageKit_ModelOnly_20261026_102020/`

อย่านำทั้งโฟลเดอร์สำรองกลับเข้า `Assets` เพราะจะทำให้ GUID ซ้ำและโค้ดต้นฉบับกลับมาทำงาน อ่านรายละเอียดการกู้คืนและการตรวจสอบได้ที่ `Docs/Medieval_Model_Only.md` ในรากโปรเจกต์
