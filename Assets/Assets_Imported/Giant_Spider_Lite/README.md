# Giant Spider Lite — free animated giant spider

A free, game-ready version of the Giant Spider from the Giant Spider Pack: a
rigged, dog-sized tarantula, dark brown and black with pale markings.

- **Mesh:** 9974 triangles (the full pack's LOD1), 4 bone influences per vertex
- **Rig:** the full 49-bone rig, with the same bone names as the full pack
- **Animation:** 4 clips at 30 fps: idle, walk and run (all loop), bite
- **Textures:** 2K base colour, normal and metallic/roughness, embedded in the files
- **Files:** `Giant_Spider_Lite.fbx` (Unity, Unreal) and `Giant_Spider_Lite.glb` (Godot, web, Blender)
- **Scale:** metres; 2.2 m leg span

Unity: Rig → Generic, root node `root`. Unreal: import as a Skeletal Mesh.
Godot: drop in the .glb.
