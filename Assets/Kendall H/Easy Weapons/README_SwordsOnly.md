# 45 FREE Fantasy Weapon Props — swords only

Original creator: Kendall H. Unity imports the pack under `Kendall H/Easy Weapons`.
Original GUIDs and AssetOrigin metadata are preserved for retained assets.

This project retains the five sword shapes in both Regular and RGBA variants,
their meshes, the vertex-colour URP shader, material and required roughness map.
All other weapon types, demo scenes and vendor scripts were removed.
The sample weapon component was stripped from retained prefabs before its script
was removed. The optional enchantment mesh is still available.

Use the scaled, grip-centred model prefabs in
`Assets/_Project/Prefabs/Weapons/FantasySwords` for gameplay integration.
See `Docs/FANTASY_SWORD_MODELS.md` for setup and cleanup details.

The original source assets remain subject to their original Asset Store license.
