# Noto Sans Thai Looped

Source: https://github.com/google/fonts/tree/main/ofl/notosansthailooped

Copyright 2022 The Noto Project Authors (https://github.com/notofonts/thai)

SIL Open Font License 1.1. The complete license is included in OFL.txt.

NotoSansThaiLooped-Variable.ttf is the original Google Fonts variable font.
NotoSansThaiLooped-Regular.ttf was generated from it using fontTools.varLib.instancer
at weight 400 and width 100 for the game's Unity/TextMeshPro Thai dialogue UI.
NotoSansThaiLooped SDF.asset contains the associated TextMeshPro glyph atlas and material.

The original font artwork and license are preserved; the static instance changes only
the font's variation axes. The game UI also references its existing Liberation Sans
fallback for symbols and Latin characters.
